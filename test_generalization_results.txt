問題: 4. 找出購買商品數量總和最多的那位客戶，並列出他的電子郵件。
回答: 沒有符合條件的資料。
SQL: SELECT c.name, c.email FROM customers AS c JOIN orders AS o ON c.id = o.customer_id JOIN order_items AS oi ON o.id = oi.order_id GROUP BY c.id, c.name, c.email ORDER BY SUM(oi.quantity) DESC LIMIT 1
Critic 通過: True | 重試次數: 0

問題: 5. 請找出狀態是『已出貨』(SHIPPED) 的訂單中，平均每筆訂單的總金額大約是多少？
回答: 根據查詢結果顯示，狀態是『已出貨』(SHIPPED) 的訂單中，平均每筆訂單的總金額約為 **12,407.83** 元。
SQL: SELECT AVG(total_amount) AS avg_shipped_amount FROM orders WHERE status = 'SHIPPED'
